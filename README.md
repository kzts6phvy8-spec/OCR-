# テキスト化データ (iPhone 用・AI スクショ解析)

スマホゲーム『戦国布武～我が天下戦国乱世演武～』の武将画面スクリーンショットを選ぶだけで、
AI (Claude) が武将情報・成長値・奥義・覚醒 (専用武器覚醒)・天賦・連携スキルを読み取り、図鑑として保存・検索・編集できるアプリです。

- **iPhone のホーム画面に追加して、普通のアプリと同じように使えます** (App Store・月額費用は不要)
- **データはすべて iPhone の中に保存** されます。サーバーはありません
- スクショは **何枚でも** まとめて選べます

## かかる費用

| 項目 | 費用 |
| --- | --- |
| アプリ本体・置き場所 (GitHub Pages) | 無料 |
| AI 読み取り: **Gemini (Google)** | **無料枠あり** (1 日・1 分あたりの回数制限。上限時は自動で待って再試行) |
| AI 読み取り: Claude (Anthropic) | 有料・前払い。標準設定で 1 枚あたり約 2〜4 円 (目安) |

設定画面で Gemini / Claude を切り替えられます (既定は Gemini)。
Gemini の無料枠では、送った画像が Google のサービス改善に使われることがあります。
AI を使わずに手動で登録・編集するだけなら費用はかかりません。

### API キーの取得

- **Gemini**: [aistudio.google.com](https://aistudio.google.com) → 「Get API key」→「Create API key」
- **Claude**: [console.anthropic.com](https://console.anthropic.com) → クレジットを購入 → API Keys → Create Key

## はじめ方 (iPhone)

1. アプリの URL を Safari で開く (公開方法は下記)
2. 共有ボタン → **「ホーム画面に追加」**
3. ホーム画面の「武将図鑑」を開き、**設定** タブで API キー (Gemini なら無料) を貼り付けて保存 → 「接続テスト (無料)」
4. **スクショ解析** タブで写真を選んで「解析開始」
   - 解析中はアプリを開いたままにしてください (iPhone はアプリを閉じると処理が止まります。次に開いた時に続きから再開します)

### 武将名が写っていない画面

天賦だけの画面など、武将名が写っていない画像は「統合先の武将」を選んでから解析してください。

### バックアップ

データは iPhone 内だけにあるため、**データ管理** タブの「バックアップを保存」で、ときどき「ファイル」アプリや iCloud Drive に保存してください。
機種変更時は新しい iPhone で「復元」から読み込めます。

## バックグラウンド解析 (アプリを閉じても解析)

iPhone のホーム画面アプリは、閉じている間は動けません (Apple の仕様)。そこで、利用者自身の Google アカウントで無料で動く
**Google Apps Script** を解析サーバーとして使えます (Gemini 選択時のみ)。

1. アプリの **設定 → バックグラウンド解析** で「サーバー用コードをコピー」
2. [script.google.com](https://script.google.com) で「新しいプロジェクト」→ コードを貼り付けて保存
3. 関数「setup」を選んで「実行」→ 権限を許可
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行ユーザー「自分」、アクセス「全員」→ デプロイ
5. 表示された URL (`https://script.google.com/macros/s/…/exec`) をアプリに貼り付けて「接続テスト」

仕組み:

- アプリは画像入りの解析依頼をサーバーに送る (`enqueue`)。送り終わればアプリを閉じてよい
- サーバーは依頼を Google ドライブの「武将図鑑_解析キュー」フォルダに置き、1 分ごとに Gemini へ送って結果を保存する
  (無料枠の上限に達したら依頼を残して次の起動で再挑戦)
- アプリを開くと結果を受け取り (`results`)、図鑑に反映して、受け取った結果をサーバーから消す (`ack`)
- 指示文・スキーマ・モデルはアプリが毎回送るので、サーバーのコード (`public/apps-script.txt`) を更新し直す必要はない
- Gemini のキーと合言葉 (端末で自動生成) は「接続テスト」でサーバーに登録され、以後は合言葉が一致する依頼だけを受け付ける

## 公開方法 (無料)

`main` ブランチに入ると GitHub Actions が自動でビルドし、GitHub Pages に公開します (`.github/workflows/deploy.yml`)。

1. リポジトリの **Settings → Pages → Source** を **GitHub Actions** にする
2. GitHub Pages を無料プランで使うには、リポジトリを **Public (公開)** にする必要があります
   - 公開されるのはアプリのプログラムだけです。API キーや武将データは各自の iPhone 内にあり、公開されません
   - 非公開のままにしたい場合は、Cloudflare Pages などの無料サービスに `dist/` を置いても動きます
3. 公開 URL: `https://<ユーザー名>.github.io/OCR-/`

## 仕組み

```
iPhone (Safari / ホーム画面アプリ)
 ├─ 写真を選ぶ → 端末内で縮小 (長辺 2000px・JPEG) → IndexedDB に保存
 ├─ 解析キュー (1 枚ずつ直列・画面消灯を防止)
 │    └─ Gemini / Claude API に直接送信 (JSON スキーマで出力を固定し、受け取った結果も検証・タイムアウト 45 秒・自動リトライ)
 ├─ (武将名, 通常/特異) で既存の武将を探し、安全にマージして保存
 └─ 図鑑表示・検索・編集・バックアップ (すべて端末内)
```

- AI の応答は **JSON スキーマ** (`src/core/ocrSchema.ts`) で形式を固定し、受け取った後もスキーマで検証します (崩れていれば再試行)。
  画面に写っていない項目は `null` で返させ、推測で埋めさせません。
- **通常 / 特異**: `(name, is_special)` で別レコード管理。自動判定は画面の【特】表記のみで、特定の武将・スキルの知識は持たせていません。
  アップロード時に「強制: 通常武将 / 強制: 特異武将」を選ぶと判定より優先されます。
- **武器覚醒後の効果** は、その画像に武器覚醒の表示が写っている場合だけ採用します。

### 複数スクショの統合ルール

| 項目 | ルール |
| --- | --- |
| 空欄 | 新しい画像の値で埋める |
| 二つ名・スキル名・成長率など | 既存値を保持 (誤読による上書き防止)。食い違いは警告表示 |
| スキル / 覚醒の効果文 | 長い方を採用 (画面端で途切れた文を補完) |
| Lv・星 | 大きい方 |
| 基礎値 | Lv が同じか上がった時に更新 |
| 天賦 | 星ごとに統合、解放状態は OR |
| 連携スキル | 相手武将ごとに統合 |
| 兵種 | 一覧は和集合、現在の兵種は最新 |
| 画像 | `gallery_images` に追加し `screenshot_count` を更新 |

## 開発

```bash
npm install
npm run dev        # http://localhost:5173
npm test
npm run typecheck
npm run build      # dist/ に静的ファイルを出力
```

```
src/
  core/       型・正規化・マージ・AI 指示文・スキーマ (画面や保存先に依存しない部分)
  client/
    lib/      端末内 DB (IndexedDB)・画像縮小・Claude 呼び出し・解析キュー・設定
    components/  画面
public/       アイコン・manifest・Service Worker (オフライン起動用)
```
